# Fotos e vídeos

Coloque aqui as fotos e vídeos do projeto, com estes nomes, para aparecerem no README principal:

| Arquivo | O que mostrar |
|---|---|
| `jogo.jpg` | O jogo funcionando, com as duas cobras se encontrando |
| `tela-go.jpg` | A tela inicial com o "GO" |
| `montagem.jpg` | A parte de dentro: ESP32, fiação e fontes |
| `terminal-derretido.jpg` | O terminal que derreteu (opcional) |
| `partida.gif` | Uma partida curta em GIF (opcional) |

Dica: o GitHub mostra GIFs direto no README. Vídeos `.mp4` de até 10 MB também funcionam se você arrastar o arquivo para a edição do README no site.
